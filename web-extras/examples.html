Reproduce RD-Agent(Q): joint factor + model optimization Finance Whole Pipeline · long-running

The agent autonomously researches alpha factors and the return-forecasting model together, evolving both across rounds against real-market backtests — the exact pipeline described in the paper.

What the loop does (paper → implementation)

  1. Research stage — sets goal-aligned prompts, forms hypotheses from quant domain priors, and maps each to concrete factor / model tasks.
  2. Development stage — the Co-STEER code-generation agent writes the factor & model code, then executes it in a qlib backtest on real CN market data.
  3. Feedback stage — evaluates the backtest (IC / Rank IC, return, drawdown), and a multi-armed-bandit scheduler picks the next research direction.
  4. Evolve — repeats, jointly improving factors and the model. The paper reports up to 2× higher annualized return with ~70% fewer factors vs classical factor libraries.
Scenario: Finance Whole Pipeline (fin_quant). Requires qlib CN data (auto-provisioned on first run) and a configured Qwen/DashScope LLM backend. For a deeper look at any run, open it in the dashboard.
