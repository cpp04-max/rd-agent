RD-Agent — Quickstart & Examples

One-click examples for the R&D-Agent scenarios. Each run is live: you can watch the agent's research → coding → feedback loop below, then open the run in the full dashboard.

💡 Runs appear in the full dashboard's history once they produce results. A run that stops immediately with “config: null” means the LLM backend is not configured — set OPENAI_API_KEY (DashScope) in Fly secrets.

1 · Implement a model from a research report best first try · ~2–10 min

Scenario: General Model Implementation. The agent reads a PDF paper/report, extracts the model design, writes the code, runs it and iterates.

Uses the bundled 1-page sample report (view it). You can also run your own PDF from the full dashboard.

2 · Data Interpreter on a Kaggle task needs Kaggle credentials

Scenario: Data Science. Upload-free: pick an MLE-Bench competition and the agent plans, codes, executes and iterates on the data.

The container needs KAGGLE_USERNAME / KAGGLE_JSON secrets to download competition data (dataset sizes vary; small competitions work best on the 1 GB machine).

3 · Finance: factor mining long-running

Scenario: Finance Data Building. qlib-based research loop that proposes, implements and backtests alpha factors.

First run auto-provisions qlib and its data (~1 GB download) — expect a slow start and watch memory.

4 · Finance: whole quant pipeline long-running

Scenario: Finance Whole Pipeline. End-to-end quant R&D: factors → model → portfolio strategy.

Same qlib prerequisites as example 3. Prefer example 3 for a first finance run.
